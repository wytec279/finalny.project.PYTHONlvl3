# finalny.project.PYTHONlvl3
финальный проект
Telegram‑бот для технической поддержки интернет‑магазина
Описание
Бот предназначен для автоматизации работы службы техподдержки интернет‑магазина «Продаём всё на свете». Он:

отвечает на часто задаваемые вопросы (FAQ);

принимает обращения клиентов;

маршрутизирует запросы в соответствующие отделы (программисты / отдел продаж);

хранит историю обращений в базе данных;

предоставляет администраторам инструменты для работы с заявками.
